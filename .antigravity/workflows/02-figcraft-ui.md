# Workflow: UI/UX Wireframing & Design System via Figcraft MCP
1. Baca `docs/PRD_Nippia_CPNS.md` dan `docs/RIVE_SPECS.md`.
2. Gunakan Figcraft MCP untuk membuat halaman `01_Design_System`: Color styles, Typography scale, dan komponen `TactileButton3D` (state Normal & Pressed dengan shadow solid 4px).
3. Gunakan Figcraft MCP untuk membuat halaman `02_App_Screens` (frame 360x800 dp):
   - `Home_Learning_Path`: Top Sticky HUD (Kategori, Streak, XP, Hearts) + Winding S-Curve Unit Nodes.
   - `Quiz_Screen`: Progress bar, Kartu soal (teks + slot gambar TIU Figural), 5 opsi taktil, dan `Feedback_Bottom_Sheet`.
   - `CAT_Tryout_Screen`: Countdown timer header, navigasi nomor soal 1-110, dan layar hasil `Passing_Grade`.
   - `Paywall_Nippia_Pro`: Perbandingan Free vs Pro dan pilihan paket 1, 3, dan 6 bulan.
